## Contract boundaries

- Bridge HTTP contract source: `packages/bridge/Source/UnrealOpenMcpEditor/Private/Bridge/` (`GET /ping` + `POST /tools/{name}` dispatch with the `{ok,result,error}` envelope shipped; mutating dispatches widen the envelope with a `gate` summary block per [Gate policy](api/bridge-http.md#gate-policy))
- Gate policy source: `packages/bridge/Source/UnrealOpenMcpEditor/Private/Gate/` (`UnrealOpenMcpGatePolicy` wraps every mutating dispatch in `checkpoint → mutate → validate → delta`; `UnrealOpenMcpVerifyGateAdapter` is the bridge→verify glue with the rule-selection + filter surface the meta-tools consult; `UnrealOpenMcpCheckpointStore` mirrors the gate's checkpoint for the meta-tools)
- Gate meta-tools source: `packages/bridge/Source/UnrealOpenMcpEditor/Private/MetaTools/UnrealOpenMcpGateMetaTools.h` (the three read-only tools `validate_edit` / `checkpoint_create` / `delta` — the explicit checkpoint → mutate → delta surface; bypass `GatePolicy.Execute` so they do not recurse)
- apply_fix source: `packages/bridge/Source/UnrealOpenMcpEditor/Private/MetaTools/UnrealOpenMcpApplyFixTool.h` (the fix-application workflow — dry-run preview lists the description / safe flag; non-dry-run applies run through the gate runner with a `FixRollback` snapshot so a corrupting fix is auto-reverted on failure or new errors under `enforce`; v1 ships the single Safe provider `clear_broken_soft_reference`)
- Instance lock + port resolver source: `packages/bridge/Source/UnrealOpenMcpRuntime/Public/Bridge/UnrealOpenMcpInstancePortResolver.h` (deterministic port + lock path), `packages/bridge/Source/UnrealOpenMcpEditor/Private/Bridge/UnrealOpenMcpBridgeInstanceLock.h` (lock file writer)
- SHA-256 source: `packages/bridge/Source/UnrealOpenMcpRuntime/Public/Crypto/UnrealOpenMcpSha256.h` (self-contained FIPS 180-4; byte-for-byte parity with Node `crypto.createHash('sha256')`)
- MCP server routing/registry source: `mcp-server/src/index.ts` (stdio server + tool dispatch; local-route tools `capabilities` and `bridge_status` resolve in-process before the live router is consulted), `mcp-server/src/live-client.ts` (live bridge HTTP client; routes `ping` → `GET /ping` and every other live tool → `POST /tools/{name}`)
- MCP capabilities surface (local rule/fix catalog + builder): `mcp-server/src/capabilities/` (shipped — `rule-catalog.ts` mirrors the implemented verify rules and fix providers; `build-capabilities.ts` assembles the capabilities payload; `unreal_open_mcp_capabilities` is local-route, no bridge hop)
- MCP tool definitions source: `mcp-server/src/tools/` (`ping` + the actor family shipped: `actor_find`, `actor_create`, `actor_modify`, `object_modify`, `actor_set_parent`, `actor_duplicate`, `actor_destroy`, and the five `actor_component_*` tools; plus the level family shipped: `level_open`, `level_save`, `level_list_loaded`, `level_set_current`, `level_unload_sublevel`, `level_get_data`, `level_create`; plus the gate meta-tools shipped: `validate_edit`, `checkpoint_create`, `delta`; plus `apply_fix`; plus `capabilities` (local-route discovery); plus the asset read family shipped: `asset_find`, `asset_get_data`; plus the Content Browser CRUD family shipped: `asset_create_folder`, `asset_copy`, `asset_move`, `asset_delete`, `asset_refresh`; plus the material family shipped: `material_create`, `material_modify`, `material_get_data`; plus asset import shipped: `asset_import` (absolute host file → `/Game` folder via `IAssetTools::ImportAssetTasks`; supported types depend on installed importers — textures/static meshes/sounds; `replace_existing` / `save` default false); plus the editor family shipped: `editor_application_get_state` / `editor_application_set_state` (P5.1 — PIE get/set: read-only `{ isPlaying, isPaused, isSimulating, editorMap }` snapshot + start/stop/pause/resume driver; ALL four transitions are latent (return `{ pending:true }`, agent polls get-state) — start/stop via `RequestPlaySession`/`RequestEndPlayMap`, pause/resume via `GEditor->SetPIEWorldsPaused` + the `bDebugPauseExecution` flag; invalid transitions return `invalid_transition`; set-state mutating, gate Enforce, `paths_hint` required) and `editor_selection_get` / `editor_selection_set` (P5.2 — actor selection get/set: get returns `{ count, actors: IdentityRef[] }`; set replaces by refs or clears with explicit `clear:true`, resolve-before-mutate aborts on a bad ref, empty call refused; set mutating, gate Enforce, `paths_hint` required); plus the console family shipped: `console_get_logs` / `console_clear_logs` / `console_run_command` (P5.3 — bounded GLog ring-buffer collector: get is a filtered read (verbosity min-severity / category / substring + limit) over a session-scoped recent-N window (NOT a full Output Log mirror; cold-start gap + overflow documented), clear empties the buffer (read-only; buffer-local), run-command runs `GEngine->Exec` and returns `{ command, output, handled }` — mutating, gate Enforce, `paths_hint` required, destructive accepted-risk) and the reflection family shipped: `reflection_method_find` / `reflection_method_call` (P5.4 — first-party UFunction reflection, no ReflectorNet: find lists UFunctions with signature/flag descriptors + matched/returned honesty; call invokes by `method` on `target` XOR `class` (CDO) with a safety allow-list (BlueprintCallable / CallInEditor only; CDO path requires static / CallInEditor) — mutating, gate Enforce, `paths_hint` required, same accepted-risk class as run-command); plus the screenshot family shipped: `screenshot_viewport` / `screenshot_game_view` / `screenshot_camera` / `screenshot_isolated` (four read-only image-capture tools returning a base64 PNG as MCP image content — the bridge emits a top-level `image: { data, mediaType }` envelope field alongside `result`, and `mcp-server/src/live-client.ts` unwraps it into an MCP image content block so the base64 never surfaces as text; viewport captures `GEditor->GetActiveViewport()` via `FViewport::ReadPixels`; game-view requires a PIE session else `pie_not_running` (checked before the GPU guard, headless-testable); camera renders from a resolved camera actor through a transient `ASceneCapture2D` at the camera transform/FOV; isolated renders a single actor against a neutral background via a show-only list (target + recursively-attached children) + HDR-over-background composite, auto-framed by the actor's bounds; all four share dimension caps [1, 2048] per side (default 1024), force opaque alpha (transparent PNGs are useless to agents), and a 40 MiB encoded byte cap (`image_too_large` on exceed); transient capture actors + render targets are cleaned up on every return path (`ON_SCOPE_EXIT` destroy + `FGCObjectScopeGuard`); read-only, gate-free — reads pixels, mutates no editor/project state; requires a GPU-backed (windowed) editor else `rendering_unavailable`); plus `bridge_status` shipped (operator / recovery-oriented health snapshot — composes the instance-lock classifier (`instance-discovery.ts#classifyInstance`) with one `/ping` probe into a coarse `status` token: `running` / `compiling` / `stopped` / `unreachable` / `dead_bridge`; returns `classification`, `ping` summary, `instance` lock summary, `recoveryHint` (non-null only for `dead_bridge`, pointing at `console_get_logs` as the interim offline Output-Log surface — the dedicated offline compile-error reader is deferred), and a human-readable `nextStep`; local-route — resolved in-process by `handleLocalTool` with no bridge POST, read-only, gate-free, never spawns the editor; a dead/stopped bridge is a successful status read, never an error); plus the Blueprint family shipped: `blueprint_create` / `blueprint_get` (P6.1 — Blueprint create/get: create makes a new Blueprint class from a resolvable parent via `FKismetEditorUtilities::CreateBlueprint` (`path` = `/Game` package path, object-path form also accepted and normalised; `parent_class` defaults to `/Script/Engine.Actor`, any Blueprintable parent allowed when `CanCreateBlueprintOfClass` passes; in-session registration via `AssetRegistry.AssetCreated` + `MarkPackageDirty`, no disk save; the any-`UObject` collision probe turns a non-Blueprint asset at the target path into a structured `asset_already_exists` instead of the engine's fatal "same fully-qualified name, different class" allocation check; on a failed create the empty package is `MarkAsGarbage`'d; mutating, gate Enforce, `paths_hint` required; get is a read-only scoped graph summary `{ name, path, parentClass, variables: [{ name, type, isArray, default? }], components: [{ name, class, parent }], functions: [{ name, nodeCount }], events: [{ name, enabled }], interfaces: [classPath], parentChain: [className] }` — events carry `enabled` so a fresh Actor Blueprint's pre-seeded DISABLED ghost event nodes (ReceiveBeginPlay/ReceiveTick) are distinguishable from enabled ones; the shared helpers `ResolveBlueprint`, path normalization, name well-formedness, `BlueprintRef` JSON, and the pin-type reverse map are the spine every later Blueprint sub-tool builds on) and `blueprint_add_component` / `blueprint_remove_component` (P6.2 — Blueprint SCS components: add creates an SCS node via the public Simple Construction Script surface (`USimpleConstructionScript::CreateNode` + `AddChildNode` under an optional scene-component `parent_component`, or `AddNode` for a root); the component class must be a concrete `UActorComponent` subclass — `CreateNode` -> `NewObject` fatally asserts on an abstract/deprecated class (e.g. `/Script/Engine.LightComponentBase`), so the `CLASS_Abstract | CLASS_Deprecated | CLASS_NewerVersionExists` guard runs BEFORE `CreateNode` and returns `abstract_component`; the variable name is checked across the SCS, the `NewVariables` list, and the parent class's properties (`name_collision`) because those namespaces share the generated class's property namespace and would otherwise only fail at compile; attachment is a scene-graph op, so both the new component and its parent must be `USceneComponent`s (`invalid_attachment`); `MarkBlueprintAsStructurallyModified` follows so a later compile rebuilds the CDO; remove deletes a node via `RemoveNodeAndPromoteChildren` (children re-parented onto the removed node's parent so a subtree is never orphaned); both mutate the asset SCS, gate Enforce, `paths_hint` required) and `blueprint_add_variable` / `blueprint_modify_variable` / `blueprint_set_default` (P6.3 — Blueprint member variables + CDO defaults: add_variable creates a typed member variable via `FBlueprintEditorUtils::AddMemberVariable` using the §3.2 pin-type forward map — the forward twin of the `PinTypeToString` reverse map blueprint_get uses; `type` token: primitive `bool`/`int`/`int64`/`byte`/`float`/`string`/`name`/`text`, math struct `vector`/`vector2d`/`rotator`/`transform`/`color`, or a resolvable object/struct path; optional `is_array` wraps the type in an array; optional `default_value` (UE text format) is stored on the variable descriptor and only takes effect after a compile lands the property on the generated class; guards reject cross-namespace name collisions — member-variable names, SCS component names, and inherited parent properties all share the generated class's property namespace (`name_collision`) — and unresolvable type tokens (`invalid_type`); modify_variable renames and/or retypes with validate-before-mutate ordering — the rename is validated (well-formed + no collision) BEFORE the retype commits, because `ChangeMemberVariableType` commits immediately and `RenameMemberVariable` is void with no collision check of its own, so a colliding/ill-formed `new_name` would otherwise leave a partial retype; at least one of `new_name`/`new_type` required; set_default writes a Class Default Object property via the property's own text importer (`ImportText_Direct`) bracketed with `PreEditChange`/`PostEditChangeProperty` so an open Details panel / property-change observers refresh — changes the CLASS DEFAULT so it affects newly-spawned instances only, not placed actors (use `actor_modify` for a placed actor); compile-first — a member variable added via `blueprint_add_variable` is NOT a property on the generated class until `blueprint_compile` lands it, so set_default on such a property reports `property_not_found` with a message pointing at `blueprint_compile`; the expected loop is add → compile → set_default; all three mutate the asset, gate Enforce, `paths_hint` required)
- MCP resources source: `mcp-server/src/resources/` (when shipped)
- E2E smoke sources: `mcp-server/src/integration.test.ts` (in-process MCP client↔server over in-memory transport — ping, `actor_find`, and `asset_find` round-trips), `mcp-server/scripts/p1-parity-smoke.mjs` / `p2-parity-smoke.mjs` / `p4-parity-smoke.mjs` (`npm run smoke:p1` / `smoke:p2` / `smoke:p4`; scripted stdio smoke against the built `dist/index.js`; healthy / bridge-down / tool-error cases). ## Contract documentation guidance

- Prefer documenting behavior and payload shapes over implementation details.
- Call out breaking changes explicitly.
- Keep examples minimal and representative.
- Unreal content paths use `/Game/...`; document live/offline/local/batch routes per tool.
